# Resonance backend (resonance-backend)

This file is the source of truth for the Resonance backend: the Synthe voice call (conversation pods), accounts, profiles, swipes and the Buddy chat that embeds the Umbrella companion. It is a living file: the owner keeps adding to it. When this file and any other document disagree, follow this file, and ask the owner if it is still unclear.

The Android app is a separate project in `../resonance-native`; see its `AGENTS.md`. Backend docs are in `docs/`; run and setup steps in `README.md`.

## About the owner and how to work with them

- The owner relies on you for most of the code and wants short, plain reports (they often write in Hinglish).
- Before any large change, say in one or two plain sentences what you are about to do and why.
- Prefer simple, readable code over clever code. Work in small steps; verify, summarise, then stop and wait.
- Never silently add a library or a paid/cloud provider; ask first. Never send user audio or text to a new provider without the owner's approval.
- If something is unclear or the docs conflict with this file, ask the owner. Do not guess.

## Verification

1. Run the tests from this folder: `.venv/bin/python -m unittest` (they use the local `synq_test` database).
2. For call or voice changes, run a real call from the app's development build when you can; otherwise say clearly what was not exercised.
3. Report honestly what you verified and what you could not verify.
